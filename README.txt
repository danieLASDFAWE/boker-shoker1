בוקר שוקר (Boker Shoker) — פרויקט אנדרואיד מלא להפקת APK
==========================================================

איך להפיק קובץ APK להתקנה בטלפון (בלי להתקין כלום במחשב):
1. חלץ את כל קבצי ה-ZIP לתיקייה במחשב.
2. פתח ריפוזיטורי חדש ב-GitHub (חינם) והעלה אליו את כל הקבצים והתיקיות.
3. היכנס ללשונית Actions ב-GitHub — הבנייה האוטומטית (Build Boker Shoker APK) תרוץ לבד.
4. בסיום (כ-2 דקות), לחץ על תוצאת הבנייה והורד את BokerShoker-APK (קובץ app-debug.apk).
5. העבר את ה-APK לטלפון האנדרואיד והתקן.

אפשרות ב' (במחשב עם Android Studio):
1. חלץ את התיקייה ופתח אותה ב-Android Studio.
2. בתפריט העליון לחץ: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
